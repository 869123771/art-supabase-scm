# Art Supabase SCM · Supply Chain Management

This repository is the supply chain management (SCM) submodule of [Art Supabase Pro](https://gitee.com/wangyanghub/art-supabase-pro). The platform tracks it at `modules/art-supabase-scm` as a Git submodule.

SCM owns its business pages, APIs, types, and domain rules. The platform provides authentication, tenant scope, menus, permissions, layout, shared components, and the common Supabase client. Business features have not been implemented yet.

Commit SCM changes here, then update the submodule pointer in the platform repository. Clone the platform with `git clone --recurse-submodules`, or initialize existing checkouts with `git submodule update --init --recursive`.
